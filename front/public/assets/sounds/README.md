# OpenCatan sound assets

Small, UI/action-oriented sound effects for frontend game actions.

All files in this directory were downloaded from Kenney asset packs released under Creative Commons CC0 1.0 Universal (public domain dedication):

- Kenney Interface Sounds: https://kenney.nl/assets/interface-sounds
- Kenney Casino Audio: https://kenney.nl/assets/casino-audio

## Suggested action mapping

| Game action | File |
| --- | --- |
| Button/menu click | `ui-click.ogg` |
| Successful command / confirmation | `ui-confirm.ogg` |
| Rejected command / error | `ui-error.ogg` |
| Select board element | `select.ogg` |
| Roll dice | `dice-roll.ogg` |
| Build road/settlement/city | `build-place.ogg` |
| Draw/buy development card | `card-draw.ogg` |
| Play development card | `card-play.ogg` |
| Receive resources | `resource-gain.ogg` |
| Maritime/domestic trade | `trade.ogg` |

Keep the Kenney license text files next to these sounds when redistributing.
